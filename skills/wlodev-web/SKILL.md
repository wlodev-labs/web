# Wlodev TanStack Router Web Apps Development

Building web apps is a repetable process of creating forms, layouts, components, etc. This skill is designed to help you build and maintain standardized, high-quality, and well-documented code, accoording to wlodev coding guidelines for TanStack Router web apps.

## Dependencies

This skill requires the `@wlodev/web` npm package to be installed in the project. It provides a set of reusable components, hooks, and utilities that follow wlodev coding guidelines.

Install the package with:

```bash
pnpm install @wlodev/web
```
